SECTION 01

Context & Clinical Objectives

In regional tertiary clinics, patient intake operates under extreme stress. Front-desk personnel frequently coordinate using fragmented physical triage slips, while diagnostic lab results trickle in through disconnected local workstations. When patient transfers occur between initial intake, triage triage desks, and attending physician suites, records become de-synchronized, creating significant clinical delays.

The primary mandate of this system was to engineer a unified, highly reliable Web-Based Hospital and Clinic Management Information System (MIS) providing instantaneous queue updates, strictly guarded Role-Based Access Control (RBAC), and persistent audit trails complying with modern data protection standards.

SECTION 02

The Operational Failure Modes

warning FAIL STATE 1: ASYNC RECORD LOSS

Fragmented Patient Intake

Reception paper entries frequently missed immediate medical warnings (e.g., severe penicillin allergies) before nurses performed preliminary vitals, leading to duplicate question cycles and elevated diagnostic risk.

timer_off FAIL STATE 2: QUEUE COLLISION

Delayed Clinical Triage Reporting

Physicians had no automated visibility into patient waiting pools. High-priority patients were stalled while low-severity reviews occupied examination rooms due to the lack of dynamic FIFO queues.

SECTION 06

Relational Entity Schema

PostgreSQL transactional DDL snippet for intake, vitals, and physician review.

-- Schema: Outpatient Triage & Clinical Encounters
CREATE TABLE patients (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  national_id_hash VARCHAR(64) UNIQUE NOT NULL,
  first_name VARCHAR(100) NOT NULL,
  last_name VARCHAR(100) NOT NULL,
  blood_group VARCHAR(5),
  allergies_summary TEXT,
  created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE triage_encounters (
  encounter_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  patient_id UUID REFERENCES patients(id) ON DELETE CASCADE,
  triage_level VARCHAR(16) NOT NULL CHECK (triage_level IN ('EMERGENT', 'URGENT', 'ROUTINE')),
  systolic_bp SMALLINT NOT NULL,
  diastolic_bp SMALLINT NOT NULL,
  pulse_rate SMALLINT NOT NULL,
  recorded_by_staff UUID NOT NULL,
  is_discharged BOOLEAN DEFAULT FALSE,
  admitted_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_encounter_live_queue 
  ON triage_encounters (triage_level, admitted_at) 
  WHERE is_discharged = FALSE;

HIPAA & Data Hardening
